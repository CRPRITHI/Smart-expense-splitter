# Smart Expense Splitter

A Java-based expense sharing application inspired by Splitwise.

## Technologies
- Java
- Maven
- JDBC
- MySQL
- Collections Framework

## Features
- User Management
- Group Creation
- Add Expenses
- Equal Expense Splitting
- Settlement Calculation

## How to Run
1. Clone the repository.
2. Configure the MySQL database.
3. Run:
   mvn clean install
   mvn exec:java
